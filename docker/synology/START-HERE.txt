OHHDAN PORTFOLIO — NAS DEPLOY (short version)
=============================================

ONE-TIME SETUP (about 30–60 min)
---------------------------------

1. ON THIS PC (in the project folder):
   npm run generate-prod-env www.ohhhdan.com
   Save the admin password it prints.

2. COPY TO NAS:
   Copy the whole folder to:
   /volume1/docker/ohhhdan-portfolio
   (Must include docker/synology/production.env)

3. ON NAS — open SSH (or Task Scheduler) and paste:

   cd /volume1/docker/ohhhdan-portfolio
   mkdir -p docker/synology/data docker/synology/scorm-packages
   sudo chown -R 1001:1001 docker/synology/data
   sudo docker compose -f docker/synology/docker-compose.yml up -d --build

4. SYNOLOGY — Reverse Proxy (Control Panel → Login Portal → Advanced):
   HTTPS  www.ohhhdan.com  :443  →  HTTP  localhost  :3000
   (Optional second rule for ohhhdan.com apex → same destination)
   Add a Let's Encrypt certificate for www.ohhhdan.com.
   If you previously used portfolio.ohhhdan.com, edit/replace that rule.

5. NAMECHEAP — Advanced DNS:
   A record  @    → your home public IP
   A record  www  → your home public IP
   (Remove any portfolio A/CNAME record if you no longer want that subdomain)

6. ROUTER — forward ports 80 and 443 to your NAS.

Done. Site: https://www.ohhhdan.com
Admin:  https://www.ohhhdan.com/admin/login  (password from step 1)


WHEN YOU UPDATE THE SITE
------------------------

On NAS (SSH):

   cd /volume1/docker/ohhhdan-portfolio
   git pull
   docker compose -f docker/synology/docker-compose.yml up -d --build

Your content in docker/synology/data/ is kept automatically.


DO I NEED DOCKER ON MY PC?
--------------------------

No. Optional only if you want to test the build before touching the NAS.
For daily edits, use:  npm run dev


AUTO-DEPLOY FROM YOUR PC (optional)
-----------------------------------

   npm run setup-deploy-agent          # once
   npm run install-weekly-deploy       # weekly sync + agent at logon
   npm run deploy-agent:serve          # or rely on logon task

Admin "Pull changes" button copies local edits to the NAS when your PC is on.
Edit deploy-agent.config.json and set sshUser to your NAS username.
